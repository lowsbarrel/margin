# Margin

A local-first Markdown editor. Notes are plain `.md` files on disk; sync blobs
are encrypted in Rust before they leave the machine. Two halves:

| Half     | Where           | Owns                                                                      |
| -------- | --------------- | ------------------------------------------------------------------------- |
| Frontend | `app/src`       | SvelteKit 5 SPA (adapter-static, `ssr = false`). UI, editor, state        |
| Backend  | `app/src-tauri` | Rust. Filesystem, crypto, S3 sync, search index, history, trash, AI, PTYs |

All commands run from `app/` unless noted. Bun is the package manager.

# The shape

Every frontend→backend call is **component → store → bridge or `$lib/bindings`
→ Rust command → module**. The command is thin: parse arguments, call the
module, return `Result<T, String>`. Logic lives in the module.

`src/lib/bindings.ts` is generated by tauri-specta (`bun run gen:bindings`) and
committed. Never edit it by hand.

## One home per concept

A fact is defined once and imported everywhere else.

| Concept                                  | Its one home                                      |
| ---------------------------------------- | ------------------------------------------------- |
| Filesystem, crypto, S3, search, AI, PTYs | a module under `src-tauri/src/`                   |
| The typed IPC surface                    | `src/lib/bindings.ts` (generated)                 |
| A domain's frontend seam                 | `src/lib/<domain>/bridge.ts`                      |
| Raw IPC (bytes, streamed events)         | `src/lib/{ai,crypto,fs,s3,terminal}/bridge.ts`    |
| `Uint8Array` ⇄ IPC marshalling           | `src/lib/ipc.ts`                                  |
| App state                                | `src/lib/stores/*.svelte.ts` (runes)              |
| Raw colour, spacing, type                | `src/lib/styles/tokens.css`                       |
| Tokens → Tailwind + shadcn               | `src/lib/styles/theme.css`                        |
| User-facing copy                         | `messages/{en,it}.json` → `m.*()`                 |
| Compiled copy                            | `src/lib/paraglide/` (generated, ignored)         |
| Version                                  | `package.json` = `Cargo.toml` = `tauri.conf.json` |
| License                                  | `LICENSE`                                         |

## Where new code goes

| You're adding                               | Put it in                                        |
| ------------------------------------------- | ------------------------------------------------ |
| Anything touching disk, keys or the network | a Rust module + a `#[tauri::command]`            |
| Shared UI                                   | `src/lib/components/`                            |
| An app-specific primitive (button, field)   | `src/lib/ui/`                                    |
| A shadcn-svelte primitive                   | `src/lib/components/ui/` via `shadcn-svelte add` |
| Cross-component state                       | `src/lib/stores/<name>.svelte.ts`                |
| A pure helper                               | `src/lib/utils/<name>.ts`                        |
| Editor behaviour                            | `src/lib/editor/live/`                           |
| Canvas behaviour                            | `src/lib/canvas/`                                |

`src/lib/utils.ts` holds only the `cn` and type helpers shadcn imports by path.

## The editor

The note editor is one CodeMirror 6 view (`src/lib/editor/live/`). **The document
is the file text, byte for byte** — no load transform, no save serializer:
`EditorState.create({ doc: fileText })` in, `state.doc.toString()` out. Markdown
renders through decorations only, so opening a note and typing one character
changes exactly that character.

Markup is hidden with replace decorations while the selection is elsewhere, and
shown raw on the selection's lines (Obsidian's rule). Block widgets (images,
rules) come from a `StateField` (`live/blocks.ts`) because CodeMirror refuses
them from a view plugin; everything else lives in `live/preview.ts`. Syntax is
`live/syntax.ts`, a `markdown()` parser with custom Lezer configs for
`WikiLink`, `Embed`, `Highlight`, `Tag`, `InlineMath`, `BlockMath`,
`ColonCallout` and `Frontmatter` — names wave-2 features match on.

Adding a live-preview feature: write `src/lib/editor/live/<feature>.ts`
exporting a CodeMirror `Extension` (or a factory returning one), then add it to
the flat `previewExtensions` list in `live/extensions.ts` (switched off wholesale
in raw Markdown mode) or to `baseExtensions` if it must survive the mode switch.
Read the editor's surroundings from the context facet instead of importing the
component:

```ts
import { contextOf } from './context';
const ctx = contextOf(view.state); // vaultPath(), notePath(), attachmentFolder(),
// exists(relPath), findByName(name), openLightbox(src, alt), openWikiLink(title),
// openContextMenu(x, y, items), code (lowlight highlighter)
```

`resolve.ts` turns Markdown destinations into vault paths (note folder → vault
root → attachment folder, `![[name]]` → attachment folder → vault-wide index):
reuse it instead of resolving paths again. CodeMirror packages load through
dynamic `import()` from `components/Editor.svelte`.

Rich blocks (`callouts.ts`, `math.ts`, `mermaid.ts`, `embeds.ts`,
`footnotes.ts`, styled by `live-blocks.css`): Obsidian `> [!type]` and legacy
`:::type` callouts, KaTeX `$…$`/`$$…$$`, mermaid fences, `![[Note]]`/`![[file]]`
embeds and footnotes. A replace decoration that spans a line break must come
from a state field — a view plugin throws. A note embed mounts a second
read-only view of the same extensions, bounded by `embedDepth`/`embedChain`.

## The vault on disk

App state lives in `<vault>/.margin/`: `vault.id`, `settings.enc`,
`workspace.enc`, `sync-base.enc`, `history/<rel>/<ts>.md` snapshots and
`trash/<unix_ms>-<n>/{files,history}/<rel>` (purged after 30 days).
Attachments share one visible vault-level folder (default `attachments`),
hidden only in the file tree. Never a dot-folder: every walker, watcher,
sync and export skips hidden paths.

# Invariants

- **Crypto lives in Rust.** Encryption, decryption and key derivation happen in
  Rust, and only Rust writes secrets to disk (encrypted). The session's vault
  key, mnemonic, S3 secret and AI key do reach JavaScript memory: never log
  them and never persist them from JS (`localStorage` holds only the theme).
- Every `#[tauri::command]` is listed in `generate_handler!` in
  `src-tauri/src/lib.rs`, or it fails at runtime. `collect_commands!` is a
  deliberate subset: raw-byte commands aren't representable in specta and are
  reached through a `bridge.ts` seam instead.
- The frontend calls the generated `commands` object. A raw `invoke()` outside
  the five allowlisted bridge files bypasses the types.
- After changing a command signature: `bun run gen:bindings`. Commit the result.
- Colours come from tokens, never literals: `tokens.css` holds the raw values,
  `theme.css` maps them onto Tailwind's `@theme` and shadcn's variable names,
  and `data-theme` on `<html>` re-resolves the lot. A literal hex in a component
  `<style>` can't follow the theme. The image lightbox is the one exception.
- `src/lib/components/ui/` is generated by shadcn-svelte and rewritten by
  `shadcn-svelte add`. Restyle through the theme, not by editing it in place.
- User-facing strings go through Paraglide. Both `en` and `it` are maintained;
  a key added to one and not the other falls back silently.
- `{@html}` is XSS on note content. Nothing is allowlisted: notes reach the DOM
  through CodeMirror decorations (raw HTML stays source text), the AI answer
  through markdown-it with raw HTML off.
- The configured AI endpoint is the one place note text leaves the machine
  unencrypted, and only because the user asked a question there. The agent
  loop reads its key from Rust state.
- Heavy work belongs off the main thread: Rust (`spawn_blocking`) for
  CPU-bound work. Never block the editor.
- Browser-only packages (editor extensions, KaTeX, Mermaid, xterm, PDF.js)
  load through dynamic `import()`. A top-level import crashes to a blank
  screen, because `ssr = false` hides it until runtime.
- One version, three files. Bump `package.json`, `Cargo.toml` and
  `tauri.conf.json` together, or the updater compares against the wrong number.
- The updater's public key is in `tauri.conf.json`; the private key exists only
  as a GitHub secret. Never commit a signing key, an S3 credential, or a
  mnemonic: that phrase *is* the vault.
- No hand-written barrel files (`lib/ui/index.ts` and
  `components/movingicons/index.ts` are grandfathered; shadcn's are generated).
  No new dependency without a reason that survives being said out loud.

`bun run check:invariants` enforces the machine-checkable half of this file.

# Style

- **Comments: default zero.** Names, types and small functions carry the
  meaning. A comment survives only if it states, in one line, a constraint the
  code cannot express: a platform quirk, a protocol rule, a security
  invariant, an order that looks wrong but is required. Never doc comments,
  banners, narration, history, TODOs or commented-out code. Tool directives
  (`eslint-disable`, `@ts-expect-error`, `svelte-ignore`, …) don't count.
  `check:invariants` fails a file with a doc comment, a multi-line comment, or
  more than 2 comments. CI config carries none at all.
- **Files stay under 400 lines**, tests included (`check:invariants` enforces
  it). Split by responsibility: Svelte subcomponents and `.svelte.ts` modules,
  Rust submodules with tests in their own file.
- Match the surrounding naming and idiom. Reuse before you write; extend the
  existing store or component instead of forking a parallel one.
- Delete dead code rather than leaving it unused.
- Small and composable. One well-named function that does one thing.

# Naming

- Branches: `<type>/<kebab-summary>`, e.g. `feat/terminal-panel`.
- Commits and PR titles: Conventional Commits, `type(scope): imperative
  summary`, lowercase, ≤72 chars. Types: feat, fix, docs, refactor, perf, test,
  build, ci, chore, revert. CI rejects violations on PRs.
- Files: kebab-case `.ts` (rune modules end in `.svelte.ts`), PascalCase
  `.svelte`, snake_case `.rs`.
- Rust commands: snake_case; they surface in TypeScript as camelCase.
- Paraglide keys: snake_case.

# Git & PRs

- Commit and push only when asked. Don't commit as a side effect of finishing.
- Work on a branch off `main`; land through a squash-merged pull request so CI
  gates it. The PR title becomes the commit subject.
- A pre-commit hook (`.githooks/pre-commit`, wired by `bun install`) runs
  `check:secrets`, `check:invariants`, `lint` and `cargo fmt --check`.
  `--no-verify` only for a genuine WIP commit.
- Releases are tags: `v<version>` triggers the signed multi-platform build and
  publishes `latest.json` for the updater.
- Never force-push `main`. Lockfiles are committed; CI installs frozen.

# Workflow

- After changing `messages/*.json`: `bun run i18n:compile` (install and `check`
  run it too).
- After changing a Rust command: `bun run gen:bindings`.
- Done means, in `app/`: `bun run lint`, `bun run check`,
  `bun run check:invariants`, `bun run check:secrets`; in `app/src-tauri`:
  `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`,
  `cargo test`. CI runs the Rust gates on Linux, macOS and Windows, because
  much of the path handling is `#[cfg(target_os = ...)]`-gated, plus
  `cargo audit` and a Linux bundle build.
- Tests are Rust `#[cfg(test)]` modules; there is no JavaScript test runner.
  Prove frontend logic with a throwaway script and UI changes in the running
  app.
- For a live Rust inner loop, run `bacon` in `app/src-tauri`
  (`brew install bacon`). Its clippy, test and fmt jobs mirror CI's `rust` job.
- New npm releases must be a week old before Bun installs them
  (`bunfig.toml`); `@tauri-apps/*` is exempt.
