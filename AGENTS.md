# Margin

A local-first Markdown editor. Notes are plain `.md` files on disk; anything
that leaves the machine is encrypted in Rust first. Two halves:

| Half     | Where            | Owns                                                        |
| -------- | ---------------- | ----------------------------------------------------------- |
| Frontend | `app/src`        | SvelteKit 5 SPA (adapter-static). UI, editor, state         |
| Backend  | `app/src-tauri`  | Rust. Filesystem, crypto, S3, search index, history         |

All commands run from `app/` unless noted.

# The shape

Every frontend→backend call is **component → store → `$lib/bindings` → Rust
command → service module**. The command is thin: parse arguments, call the
module, return `Result<T, String>`. Logic lives in the module.

`src/lib/bindings.ts` is generated by tauri-specta (`pnpm gen:bindings`) and
committed. Never edit it by hand.

## One home per concept

A fact is defined once and imported everywhere else.

| Concept                        | Its one home                                 |
| ------------------------------ | -------------------------------------------- |
| Filesystem, crypto, S3, search | a module under `src-tauri/src/`              |
| The typed IPC surface          | `src/lib/bindings.ts` (generated)            |
| Raw-byte IPC                   | `src/lib/{crypto,fs,s3}/bridge.ts`           |
| App state                      | `src/lib/stores/*.svelte.ts` (runes)         |
| Raw colour, spacing, type      | `src/lib/styles/tokens.css`                  |
| Tokens → Tailwind + shadcn     | `src/lib/styles/theme.css`                   |
| User-facing copy               | `messages/{en,it}.json` → `m.*()`            |
| Version                        | `package.json` = `Cargo.toml` = `tauri.conf.json` |
| License                        | `LICENSE`                                    |

## Where new code goes

| You're adding                             | Put it in                             |
| ----------------------------------------- | ------------------------------------- |
| Anything touching disk, keys or the network | a Rust module + a `#[tauri::command]` |
| Shared UI                                 | `src/lib/components/`                 |
| A generic control                         | `src/lib/components/ui/` (shadcn)     |
| Cross-component state                     | `src/lib/stores/<name>.svelte.ts`     |
| A pure helper                             | `src/lib/utils/`                      |
| Editor behaviour                          | `src/lib/editor/`                     |

# Invariants

- **Plaintext and keys never reach JavaScript.** Encryption, decryption and key
  derivation happen in Rust. A feature that needs either gets a command.
- Every `#[tauri::command]` is listed in `generate_handler!` in
  `src-tauri/src/lib.rs`, or it fails at runtime. `collect_commands!` is a
  deliberate subset: raw-byte commands aren't representable in specta and are
  reached through a `bridge.ts` seam instead.
- The frontend calls the generated `commands` object. A raw `invoke()` outside
  the four allowlisted bridge files bypasses the types.
- After changing a command signature: `pnpm gen:bindings`. Commit the result.
- Colours come from tokens, never literals: `tokens.css` holds the raw values,
  `theme.css` maps them onto Tailwind's `@theme` and shadcn's variable names,
  and `data-theme` on `<html>` re-resolves the lot. A literal hex in a component
  `<style>` can't follow the theme.
- `src/lib/components/ui/` is generated by shadcn-svelte and rewritten by
  `shadcn-svelte add`. Restyle through the theme, not by editing it in place.
- User-facing strings go through Paraglide. Both `en` and `it` are maintained —
  a key added to one and not the other falls back silently.
- `{@html}` is XSS on note content. It is allowlisted in one file.
- Heavy work belongs off the main thread: Rust for CPU-bound work, a Web Worker
  for graph layout. Never block the editor.
- Heavy editor dependencies load through dynamic `import()`. A top-level import
  of a browser-only package crashes to a blank screen, because `ssr = false`
  hides it until runtime.
- One version, three files. Bump `package.json`, `Cargo.toml` and
  `tauri.conf.json` together, or the updater compares against the wrong number.
- The updater's public key is in `tauri.conf.json`; the private key exists only
  as a GitHub secret. Never commit a signing key, an S3 credential, or a
  mnemonic — that phrase *is* the vault.
- No barrel files (two are grandfathered). No new dependency without a reason
  that survives being said out loud.

# Style

- **Comments are rare and load-bearing.** A comment earns its place only by
  stating a constraint that isn't obvious from the code — in one line. Never
  narrate what the next line does. If it needs a paragraph, it belongs in the
  README or a doc, not the file.
- Match the surrounding naming and idiom. Reuse before you write; extend the
  existing store or component instead of forking a parallel one.
- Delete dead code rather than leaving it unused.
- Small and composable. One well-named function that does one thing.

# Naming

- Branches: `<type>/<kebab-summary>`, e.g. `feat/graph-clustering`.
- Commits and PR titles: Conventional Commits — `type(scope): imperative
  summary`, lowercase, ≤72 chars. Types: feat, fix, docs, refactor, perf, test,
  build, ci, chore, revert. CI rejects violations on PRs.
- Files: kebab-case `.ts`, PascalCase `.svelte`, snake_case `.rs`.
- Rust commands: snake_case; they surface in TypeScript as camelCase.
- Paraglide keys: snake_case.

# Git & PRs

- Commit and push only when asked. Don't commit as a side effect of finishing.
- Work on a branch off `main`; land through a pull request so CI gates it.
- A pre-commit hook (`.githooks/pre-commit`, wired by `pnpm install`) runs
  `check:secrets`, `check:invariants`, `lint` and `cargo fmt`. `--no-verify`
  only for a genuine WIP commit.
- Releases are tags: `v<version>` triggers the signed multi-platform build and
  publishes `latest.json` for the updater.
- Never force-push `main`. Lockfiles are committed; CI installs frozen.

# Workflow

- After changing `messages/*.json`: `pnpm i18n:compile` (install and `check` run
  it too).
- After changing a Rust command: `pnpm gen:bindings`.
- Done means `pnpm lint`, `pnpm check`, `pnpm check:invariants`,
  `pnpm check:secrets`, `cargo fmt --check` and `cargo clippy -- -D warnings`
  all pass. CI additionally runs clippy on macOS and Windows, because much of
  the path handling is `#[cfg(target_os = ...)]`-gated.
- `pnpm check:deprecated` is a type-aware gate for `@deprecated` symbols. It is
  very slow — minutes, not seconds — so it runs in CI only, on a timeout.
